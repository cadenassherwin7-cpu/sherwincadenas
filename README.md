# Information Security Fieldwork Journal

A responsive academic blog based on the visual structure and minimalist editorial feel of the supplied reference blog.

## Files

- `index.html` — homepage
- `blog-post-2.html` — complete Blog Post 2
- `styles.css` — responsive styling
- `script.js` — mobile navigation

## Run locally

Open `index.html` in a browser.

For a local development server, from this folder run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

The visual system intentionally avoids flashy cybersecurity effects and uses a text-led academic blog layout: generous whitespace, restrained colors, serif editorial headings, readable article width, subtle dividers, and a simple footer.

The article uses general academic treatment examples and avoids exposing credentials, personal information, or specific sensitive vulnerabilities.
